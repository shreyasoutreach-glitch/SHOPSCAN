# A11yForge adversarial simulation lab

A11yForge is the working name for the former ShopScan engine.

Every discovered defect becomes a regression fixture. Every false positive becomes a negative fixture. Every unsafe repair becomes a repair regression.

Difficult simulation families include SPA mutations, delayed components, shadow DOM, modal focus, keyboard menus, cart drawers, variant selectors, iframe boundaries, mobile-only controls, dynamic IDs, malformed HTML, overlays and hydration failures.

A pass means the system reports the expected observation without unsafe repair. This is a quality program, not a legal or WCAG certification claim.
